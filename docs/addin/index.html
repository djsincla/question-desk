Web page on a slide

Shows any live web page on this slide. For a Question Desk session it shows the live QR code, which keeps changing during the slideshow, just like the room screen.

Paste any link — with or without the https:// — such as a news site, a survey or your own website.

For a session's QR code, copy the link from the Question Desk Admin page: Sessions → Links → PowerPoint slide (the room screen link works too).

Some sites don't allow being shown inside another page; those stay blank, and a note says so.
